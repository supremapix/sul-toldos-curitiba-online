# Design Spec - Toldos Comerciais Curitiba

## Typography
- **Font Family**: 'Inter', -apple-system, BlinkMacSystemFont, 'Segoe UI', Roboto, sans-serif
- **Font Sizes**:
  - H1 Hero: 2.5rem (mobile) to 3.5rem (desktop), font-weight: 800
  - Section Title H2: 2.25rem, font-weight: 800
  - Card Title H3: 1.25rem, font-weight: 700
  - Body: 1rem (16px), line-height: 1.6

## Colors
- **Background**: `#0d0d0d`
- **Foreground**: `#fafafa`
- **Card Background**: `#141414`
- **Primary / Accent**: `#e53e3e` (Red)
- **Secondary / Header**: `#241f21`
- **Muted Foreground**: `#a6a6a6`
- **Border**: `#2a2a2a`

## Layout & Spacing
- **Container Max-Width**: 1280px with 1rem padding horizontal
- **Border Radius**: 0.5rem (`--radius`)
- **Breakpoints**: Mobile (< 768px), Tablet (768px - 1024px), Desktop (> 1024px)
